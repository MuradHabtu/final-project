How to Use ShowFinder

1. Search for a show

Type a show name into the search bar on the home page and click Search. ShowFinder will return matching TV shows from the TVMaze API.

2. View trending shows

The Trending Today section displays shows currently airing in the United States.

3. Save favorites

Click the Save Favorite button on any show card. This stores the show in the Supabase database.

4. Load your favorites

Click Load Favorites to retrieve saved shows from the database.
